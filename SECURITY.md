# Security Policy

## Supported versions

Only the [latest release](https://github.com/comax424/x-thread-toggle/releases/latest) receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report them privately via GitHub instead:
**Security → [Report a vulnerability](https://github.com/comax424/x-thread-toggle/security/advisories/new)**.

Please include what you found, how to reproduce it and which version you used.
This is a hobby project, so responses are best effort — usually within a few days.

## Scope

In scope: the extension's own code in this repository (for example, content from x.com being rendered unsafely,
data being sent anywhere other than x.com, or permissions beyond what is documented in the README).

Out of scope: vulnerabilities in x.com or X's apps themselves — please report those to X directly.
